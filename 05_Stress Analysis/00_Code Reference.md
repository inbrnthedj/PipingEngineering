# Stress Analysis
*this will also serve as my checklist to study*

To perform a stress analysis, the following codes are considered:

*PIPING SYSTEMS*
- **ASME B31.1** - Power Piping
- **ASME B31.3** - Process Piping
- ASME B31.4 - Pipeline transportation systems for Liquid Hydrocarbons
- ASME B31.8 - Pipeline transportation systems for gas transmissions / distribution

*PRESSURE VESSELS & HEAT EXCHANGERS*
- ASME Section VIII, Division 1: Unfired Pressure vessels
- ASME Section VIII, Division 2: Design-by-Analysis standard using detailed stress categorization and fatigue analysis
- EN13445 (Part 3 - Design): European standard for Unfired pressure vessels with dedicated rules for Design by Analysis (DBA) (Annex B&C)
- API 650/ API 620: Welded steel tanks for oil storage and low-pressure storage

*STRUCTURAL STEEL & SUPPORTS*
- AISC 360: Specification for Structural Steel Buildings (ASD and LFRD methods) for industrial support frames
- Eurocode 3 (EN 1993): Design of steel structures in Europe, combined with Eurocode1 (EN 1991) for environmental and mechanical actions/loads
- API RP 2A-WSD / DNV-RP-C203: Standards for offshore platforms, wave loads, and fatigue evaluation.
